Локальный standkit_agent — headless-служба, которую ставят на хост со стендами, чтобы удалённый диспетчер BPMkitStand (этот дашборд на машине оператора) мог федеративно управлять стендами этой машины по HTTP — см. значение transport: agent у записи стенда в реестре.

Агент нужен ТОЛЬКО для удалённого управления. Если вы управляете стендами локально, с этой же машины, где они запущены (transport: local), агент не требуется — ядро standkit работает со стендами напрямую.

Кнопки ниже запускают/останавливают такой агент на ТЕКУЩЕЙ машине с параметрами из вкладки «Настройки» (host/port/токены/TLS) — чтобы другие хабы могли подключиться к стендам этой машины.

Основные
Удалённые стенды

Нужно, только если часть стендов живёт на других хостах под управлением standkit-agent. Для локальных стендов оставьте пустым.

Агент (расширенное)

Параметры запуска локального standkit-agent — демона, через который к этому хосту обращается диспетчер с другой машины. Блок нужен администратору хоста удалённого стенда; при работе только с локальными стендами трогать его не нужно.

Осознанный обход защиты: без этого флага агент не стартует на внешнем адресе без TLS. Только для разработки, никогда на прод.
