Зарегистрировать стенд

Регистрирует уже существующий стенд в общем реестре — каталог, БД и дистрибутив должны быть готовы заранее (это не провижининг нового стенда).

Это НЕ то же самое, что «Проверять сертификат» (verify_tls) ниже: тот флаг относится к пробе САМОГО СТЕНДА. Выключать проверку — только для дев-контура; правильный путь — указать agent_ca.
Выключение — послабление для дев-контуров с self-signed сертификатом. Для прод-стендов флаг должен оставаться включённым.
Адрес — с точки зрения хоста, где выполняется проба (ядро на этой машине либо агент на хосте стенда), а не машины оператора. Redis внутри compose без проброса порта наружу даст down, а не unknown. Задавать нужно оба поля сразу: половина пары — ошибка регистрации.

Локальный standkit_agent — headless-служба, которую ставят на хост со стендами, чтобы удалённый диспетчер BPMkitStand (этот дашборд на машине оператора) мог федеративно управлять стендами этой машины по HTTP — см. значение transport: agent у записи стенда в реестре.

Агент нужен ТОЛЬКО для удалённого управления. Если вы управляете стендами локально, с этой же машины, где они запущены (transport: local), агент не требуется — ядро standkit работает со стендами напрямую.

Цикл обновления MCP выключен по умолчанию. Он включится не раньше, чем издатель выпустит ключ подписи артефактов и переведёт канал на HTTPS: до тех пор подпись бинаря подтвердить нечем. Основные
Удалённые стенды

Нужно, только если часть стендов живёт на других хостах под управлением standkit-agent. Для локальных стендов оставьте пустым.

Агент (расширенное)

Параметры запуска локального standkit-agent — демона, через который к этому хосту обращается диспетчер с другой машины. Блок нужен администратору хоста удалённого стенда; при работе только с локальными стендами трогать его не нужно.

Осознанный обход защиты: без этого флага агент не стартует на внешнем адресе без TLS. Только для разработки, никогда на прод.

Канал обновлений

Доставка от издателя: паттерны разработки, обновления MCP и список отозванных лицензий. Состояние и кнопки — на вкладке «Обновления». В свободной редакции секция ни на что не влияет.

Главный рубильник. Выключен — фоновые проверки не выполняются и кнопки действий недоступны; статус при этом продолжает показываться.

Цикл выключен по умолчанию и остаётся таким, пока издатель не выпустит ключ подписи артефактов и не переведёт канал на HTTPS. Включение НЕ отменяет проверку подписи бинаря: без валидной подписи обновление не применяется в принципе.

Файл кладётся в каталог подготовки и проверяется, но ничего в поставке не меняется: установку запускает только кнопка «Установить».

Ужесточение на будущее: механизма подписи markdown у издателя пока нет, и включение сегодня остановит доставку паттернов целиком.
