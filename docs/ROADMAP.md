# ROADMAP — standkit / BPMkitStand

Дорожная карта **приложения** (свободное ядро `standkit` + дашборд
`standkit_hub` + агент `standkit_agent`). Полный список незакрытых «заделов» с
ссылками на код — [BACKLOG.md](BACKLOG.md). Архитектура — [ARCHITECTURE.md](ARCHITECTURE.md).
Решения — [adr/](adr/). История изменений — [CHANGELOG.md](CHANGELOG.md).

Текущая версия на PyPI: **0.9.0** ([все выпуски](https://pypi.org/project/standkit/)).
Python ≥ 3.10, ядро и агент — stdlib-only. Карта документации — [README.md](README.md).

## ✅ Сделано

- **Ядро `standkit`** — реестр стендов, модель `Stand` (`transport`
  `local`/`agent`, `host_kind` kestrel/iis/docker/k8s), быстрые health-пробы
  (процесс/HTTP/БД/Redis по TCP), жизненный цикл kestrel (headless start/stop/
  restart, pidfile), Secret-first доступ к секретам (env→keyring→фолбэк).
- **Hosting backends** (ADR-0001/0002) — kestrel / IIS (`appcmd`) / Docker
  (`docker`,`compose`) / Kubernetes (`kubectl`). Диспетчеризация по `host_kind`,
  прозрачна для хаба/агента/клиента.
- **Дашборд `standkit_hub`** — веб-UI (stdlib `http.server` + vanilla JS): список
  стендов + состояние, старт/стоп/рестарт (честный старт до HTTP-ok), очистка
  Redis, тёмная тема, модалка «Зарегистрировать стенд» (пишет в общий
  `projects.json`), панель «Текущее состояние» (tail лога текущей сессии),
  федерация с удалёнными агентами.
- **Агент `standkit_agent`** — stdlib-only HTTP/RPC с прод-харденингом: TLS/mTLS,
  fail-closed loopback, скоупы control/readonly, rate-limit/lockout, аудит.
- **Консольные точки входа** — `standkit-hub` / `standkit-gui` / `standkit-agent`.
- **Канал обновлений издателя** (`standkit_companion`, 0.9.0) — транспорт доставки
  паттернов, релизов MCP и списка отзыва лицензий: планировщик трёх циклов в одном
  фоновом потоке хаба, stdlib-only HTTP и проверка подписи Ed25519, вкладка
  «Обновления» и маршруты `/api/companion/*`, CLI `python -m standkit_companion`.
  Редакция определяется наличием пакета (мягкий импорт в хабе) — [ADR-0005](adr/0005-companion-transport-in-mit-core.md).

### Состояние канала обновлений по циклам

| Цикл | Состояние |
|---|---|
| **Паттерны** | **работает**: дельта-синхронизация с курсором `(since, since_id)`, проверка целостности, override-корень, управляемый блок индекса. Включён по умолчанию |
| **Релизы MCP** | **код готов и покрыт тестами, цикл выключен по умолчанию** (`releases.enabled = false`). Включается владельцем после того, как издатель выпустит ключ подписи артефактов и переедет на HTTPS — до тех пор fail-closed политика отвергала бы всё, что приезжает |
| **Откат** | **готов**: история применённых версий, резервные копии бинаря, `rollback` в CLI и в UI |
| **Отзыв лицензий** | **готов**: публичный эндпоинт без конверта, обязательная проверка подписи, побайтовая запись документа |

### Правки текущего цикла (0.5.1 → 0.5.2) — см. [CHANGELOG.md](CHANGELOG.md)

- IIS: жизненный цикл **по Site** (App Pool не трогаем — может быть общим),
  корректный детект остановленного сайта (http.sys держит порт), читаемая ошибка
  `appcmd` (OEM-декод) + подсказка «запустить от администратора» — [ADR-0004](adr/0004-iis-site-scoped-lifecycle.md).
- Честный отказ при остановке стенда, запущенного вне диспетчера (нет pidfile).
- Хаб: колонка Redis с номером базы; HTTP-значение — ссылка; колонки не «прыгают»;
  модалки не закрываются при выделении текста; фидбэк кнопки «Обновить»; лёгкие
  логи IIS (только за сегодня + чтение хвоста файла); первый запуск создаёт папку
  реестра; Ctrl+C завершает дашборд без трейсбека.
- Упаковка: SPDX-лицензия (без deprecation-warning setuptools).

## 🌐 Экосистема: что здесь, а что у издателя

- **Companion (канал обновлений)** — здесь живёт **транспорт**: пакет
  `standkit_companion` (HTTP-клиент, планировщик, проверка целостности и подписи,
  раскладка файлов, откат) плюс его точка подключения к хабу. Всё остальное — у
  издателя: лицензия и конверты, содержимое паттернов, подписанные бинари MCP,
  приватные ключи подписи, сам бэкенд `/v1/content/*`. Без лицензионного конверта
  пакет ничего не делает и честно об этом сообщает; конверт он не резолвит сам, а
  спрашивает у CLI MCP (`bpmkit setup companion-context --json`). Обоснование смены
  прежней формулировки «здесь не живёт», отвергнутые альтернативы и закрытый список
  «чего модуль не делает никогда» —
  [ADR-0005](adr/0005-companion-transport-in-mit-core.md).
- **Провижининг, деплой пакетов, БД-операции, генерация документов** — по-прежнему вне
  этого репозитория, зона платного BPMkit (см. [ARCHITECTURE.md](ARCHITECTURE.md) →
  «Границы free (MIT) / paid»).
