# Документация BPMkitStand — что где лежит

Карта документов репозитория: **кому**, **о чём** и **когда открывать**.
Если не знаете, с чего начать — начните с [кукбука](../standkit_hub/web/cookbook.html).

## С чего начать

| Роль | Открывайте это |
|---|---|
| Первый запуск, «просто хочу дашборд» | [Кукбук](../standkit_hub/web/cookbook.html) → разделы 01–03 |
| Ставлю агента на Linux-хост | [COOKBOOK_LINUX.md](COOKBOOK_LINUX.md) — пошагово, по живому прогону |
| Настраиваю удалённые стенды | [REMOTE_STANDS.md](REMOTE_STANDS.md) + [Кукбук](../standkit_hub/web/cookbook.html) §06 |
| Что-то не работает | [Кукбук](../standkit_hub/web/cookbook.html) §09 «Траблшутинг», для Linux-агента — [COOKBOOK_LINUX.md](COOKBOOK_LINUX.md) «Типичные проблемы» |
| Настраиваю канал обновлений | [Кукбук](../standkit_hub/web/cookbook.html) §08 «Канал обновлений» + [ADR-0005](adr/0005-companion-transport-in-mit-core.md) |
| Правлю код | [ARCHITECTURE.md](ARCHITECTURE.md) → [adr/](adr/) → [BACKLOG.md](BACKLOG.md) |
| Планирую работы | [ROADMAP.md](ROADMAP.md) + [GAPs/](GAPs/README.md) |

## Все документы

### Для оператора

| Документ | О чём | Формат |
|---|---|---|
| [**Кукбук**](../standkit_hub/web/cookbook.html) | Главный документ продукта: обзор, установка (Windows и Linux раздельно), дашборд экран за экраном, реестр стендов, виды хостинга, удалённые стенды и агент, безопасность, канал обновлений, траблшутинг, границы free/paid | HTML, один самодостаточный файл |
| [COOKBOOK_LINUX.md](COOKBOOK_LINUX.md) | Развёртывание агента на Linux: PEP 668 и pipx/venv, реестр, секреты, systemd, TLS/mTLS, эксплуатация, подключение из дашборда | Markdown |
| [REMOTE_STANDS.md](REMOTE_STANDS.md) | Удалённые стенды: контракт агента, поля реестра, установка службы, TLS | Markdown |
| [HOSTING.md](HOSTING.md) | Виды хостинга (`host_kind`): kestrel / iis / docker / k8s — что делает диспетчер под капотом | Markdown |
| [../SECURITY.md](../SECURITY.md) | Модель безопасности и остаточные риски агента | Markdown |

> 💡 **Почему кукбук лежит в `standkit_hub/web/`, а не здесь.** Это не только
> документ, но и статика дашборда: кнопка «?» в шапке открывает его по
> `/static/cookbook.html`, и в колесо PyPI он попадает потому, что физически
> лежит внутри пакета. Перенос в `docs/` сломал бы офлайн-справку у всех, кто
> поставил пакет через `pip`/`pipx`.

### Три списка «что ещё не так» — не путать

| Список | Критерий попадания | Пример |
|---|---|---|
| [ROADMAP.md](ROADMAP.md) | Порядок **крупных работ** по версиям | «Транспорт ssh» |
| [BACKLOG.md](BACKLOG.md) | **Упомянуто в коде, но не реализовано**: заглушка, зарезервированное значение, задел | `redis_deep_check` всегда возвращает `SKIPPED` |
| [GAPs/](GAPs/README.md) | **Код работает по спецификации, а сценарий оператора всё равно ломается**: настройку негде задать, отказ не объяснён, рецепт не описан | `http: down` без объяснения причины |

## Куда писать новое

| Что нашли | Куда завести |
|---|---|
| Заглушка/задел в коде | строка в [BACKLOG.md](BACKLOG.md) со ссылкой на файл и символ |
| Оператор упёрся, хотя код прав | новый файл `GAP-NNN-имя.md` в [GAPs/](GAPs/README.md) по правилам оттуда |
| Выбор между вариантами реализации | новый ADR в [adr/](adr/) |
| Рецепт для оператора | раздел кукбука (или `COOKBOOK_LINUX.md`, если он про Linux-агента) |
| Изменение, видимое пользователю | строка в `## [Unreleased]` в [CHANGELOG.md](CHANGELOG.md) |

> ⚠️ Репозиторий **публичный**. Примеры только анонимные: `stand-a`,
> `client-uat`, `example-host`, `10.0.0.10`. Реальные имена стендов, хостов и
> адреса заказчиков в документацию не попадают — правило действует для всех
> файлов этой папки.
