## [0.5.2] — 2026-07-25

### Изменено
- **IIS: жизненный цикл по Site.** Стоп/рестарт/детект работают по **Site**
  стенда; **App Pool не трогаем** (может быть общим с другими приложениями).
  App Pool задействуется только когда `iis_site` не задан. Детект «жив» — по
  состоянию сайта; открытый TCP-порт больше не маскирует остановленный сайт
  (http.sys держит порт). См. [ADR-0004](adr/0004-iis-site-scoped-lifecycle.md).
- **Читаемые ошибки внешних команд.** Вывод `appcmd`/`docker`/`kubectl`
  декодируется utf-8 → OEM (cp866) → cp1251 — больше не «кракозябры».
- **Хаб — тяжёлые логи IIS.** Панель «Текущее состояние» берёт логи только за
  сегодня и читает лишь хвост файла (до 4 МБ) — дневной IIS-лог в сотни МБ не
  грузится целиком.
- Упаковка: SPDX-выражение лицензии (`license = "MIT"`, `license-files`) —
  убран deprecation-warning setuptools.

### Добавлено
- Подсказка «запустите диспетчер от имени администратора» при ошибках `appcmd`
  из-за нехватки прав (IIS требует elevation).
- Кнопка «Обновить» даёт обратную связь (блокировка + «Обновление…» + время).
- Колонка **Redis** в таблице стендов с номером базы.
- Обратная связь и надёжность первого запуска: папка реестра создаётся при старте
  диспетчера и при первой записи.

### Исправлено
- **Честный отказ** при остановке стенда, запущенного вне диспетчера (нет
  pidfile): вместо мнимого «остановлено» — понятная ошибка.
- Логи стенда ищутся в подпапках по датам (рекурсивный листинг) — раньше хаб
  ошибочно сообщал «в каталоге нет файлов».
- Модалки не закрываются при выделении текста мышью с отпусканием за краем окна.
- Колонки таблицы не «прыгают» при смене статуса; HTTP-значение — кликабельная
  ссылка; кнопки в модалках не слипаются.
- `Ctrl+C` завершает `standkit-hub` чисто, без трейсбека `KeyboardInterrupt`.
- Дедуп SVG-ассетов; TODO-докстринги урезаны до ссылок на документацию/бэклог.

## [0.5.0] — 2026-07-24

### Добавлено
- **Kubernetes** hosting backend (`host_kind=k8s`) через `kubectl`
  (scale/rollout/get/logs) — [ADR-0002](adr/0002-k8s-backend.md).
- **Регистрация стенда из UI** — модалка «Зарегистрировать стенд» в дашборде
  (пишет в общий `projects.json`).
- Hosting backends kestrel/iis/docker — [ADR-0001](adr/0001-hosting-backends.md)
  (v0.4.0), k8s — v0.5.0.
